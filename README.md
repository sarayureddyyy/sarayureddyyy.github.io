# Sarayu Reddy — Personal portfolio

A responsive, dependency-free portfolio for GitHub Pages, covering selected projects, background, experience, and contact information.

## Preview locally

Run `python -m http.server 8000` from this directory, then visit `http://localhost:8000`. No build step or package installation is required.

## Editing

- Edit `index.html` to update projects, experience, skills, résumé links, and contact details.
- Edit the variables in `styles.css` to change the palette.
- Replace `favicon.svg` to change the browser icon.
- Project illustrations are decorative HTML/CSS compositions, not application screenshots.

Content is based on the public `sarayureddyyy/resume-website` portfolio and GitHub repository descriptions. Review role information when it changes. Résumé links point to the existing résumé website.

## Publishing

Use GitHub Pages with the default branch and `/ (root)` as the source. Once merged, an existing branch-based Pages configuration will publish the changes automatically.

## Accessibility

Includes semantic landmarks, a skip link, keyboard focus, descriptive links, and reduced-motion support. Content and navigation work without JavaScript. Fonts and artwork use local/system resources with no third-party scripts.
